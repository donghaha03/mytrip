# 데이터와 영수증 처리

## 국가·통화

국가·지역 249개는 ISO 3166-1 alpha-2 코드로 저장합니다. 한국어·영문 표시 이름은 [country-list](https://github.com/umpirsky/country-list)의 CLDR 기반 목록을 사용합니다. [MIT 라이선스](../licenses/country-list.txt)를 함께 제공합니다.

사용 통화는 [Unicode CLDR 48 currencyData](https://github.com/unicode-org/cldr-json/blob/48.0.0/cldr-json/cldr-core/supplemental/currencyData.json)의 2026-10-04 기준 유효한 법정통화입니다. 복수 통화가 유효하면 CLDR의 첫 통화를 기본값으로 사용하고, 지출에는 결제 통화를 별도로 선택할 수 있습니다. 일반 사용 통화가 없는 지역은 `XXX`로 표시하고 환율을 만들어 넣지 않습니다. [Unicode 라이선스](../licenses/unicode.txt)를 포함합니다.

`scripts/generate_countries.mjs`로 표시 목록을 재생성합니다. 이전 여행의 통화 필드는 그대로 읽으며 새 여행은 선택 국가의 `countryCode`도 저장합니다. 여러 유로 사용 국가가 같은 국가로 복원되지 않습니다. 기존 유럽 단축 선택은 `EU`로 유지합니다.

새 통화도 기존 06:00 KST 서버 스냅샷에서 읽습니다. 새로 추가된 통화에는 다음 정기 갱신 전까지 환율이 없을 수 있습니다. 환율이 없는 기록은 통화별로 표시하고 원화 총합·파이차트에서 임의 합산하지 않습니다. 제공자가 지원하지 않는 통화도 같은 방식으로 처리합니다.

## 지출 구성

사용방법의 출발 지도는 [Natural Earth](https://github.com/nvkelso/natural-earth-vector)의 110m 국가 경계와 50m 대표 좌표를 단순화해 앱에 포함합니다. 작은 지역은 10m map units 좌표를 사용하며 UM은 Wake Atoll, 유럽 단축 선택은 프랑스·독일·이탈리아의 중심을 예시로 사용합니다. [공개 도메인 자료](https://www.naturalearthdata.com/about/terms-of-use/)이며 실시간 지도나 실제 항공 경로가 아닙니다. 여행이 없을 때는 한국→일본 예시를 보여줍니다.

여행 요약·상세의 집계 범위는 해당 여행에 기록된 전체 기간입니다. 모든 항목은 현재 상단 표시 환율로 정수 환산합니다. 예산 막대 길이는 순지출의 예산 소진율(0~100%)이고, 색상의 비율은 취소 후 남은 양수 지출의 카테고리 구성입니다. 음수 환불은 파이차트에서 제외하고 별도 환불 조정·순지출로 표시합니다. 취소·부분취소 금액은 이미 순지출에서 제외되어 재차 차감하지 않습니다. 거절 결제는 제외합니다.

## 영수증

- 인식 엔진: [Tesseract.js 6.0.1](https://github.com/naptha/tesseract.js), core 6.1.2, [tessdata_fast 4.1.0](https://github.com/tesseract-ocr/tessdata_fast/tree/4.1.0). Apache-2.0 라이선스는 `web/ocr/`에 포함합니다.
- 카메라는 사용자가 시작할 때만 요청합니다. 후면 카메라를 우선 요청하지만 실제 장치·브라우저가 선택합니다. 촬영·이탈·백그라운드 전환 시 스트림을 중지합니다. HTTPS 웹 환경이 필요합니다.
- 사진은 기기 메모리에서만 처리합니다. OCR 엔진·영어/한국어/일본어 모델은 앱과 같은 출처에서 내려받습니다. 영수증 사진·OCR 원문을 외부 서비스로 전송하지 않습니다. 유료 OCR, 가입, API 키가 필요하지 않습니다.
- 사진·원문은 검토 화면을 닫으면 폐기합니다. 확인한 지출 필드·품목(이름, 수량, 금액)과 중복 확인용 상호명·일자·통화·금액 조합을 기록에 남깁니다. 원본 사진을 Firestore나 브라우저 저장소에 저장하지 않습니다.
- 인식은 최대 90초입니다. 실패 시 사진을 유지하고 인식 재시도·재촬영·수동 입력을 제공합니다. 기존 수동 입력을 바꾸기 전에 확인을 요청합니다.
- 상호명·날짜·최종 결제금액·통화는 추천값입니다. 여러 총액·모호한 통화 기호·모호한 날짜를 확정하지 않습니다. 소계·세금·총액을 합산하지 않습니다. 분류 추천은 수정할 수 있습니다.
- 품목은 수량·금액이 명시된 행에서 제안하며 검토 화면에서 수정하거나 제외할 수 있습니다. 품목 금액을 결제 총액에 다시 더하지 않습니다. 화면 재촬영·기울기·줄무늬·작은 글자는 인식 오류를 일으킬 수 있습니다.
- 초점·화질 자동 감지는 없습니다. 동일 영수증 의심은 확인만 요청하며 별개의 정상 지출을 차단하지 않습니다. 인식 결과는 자동 저장하지 않습니다.

브라우저별 실제 카메라 권한·장치 동작은 사용 기기에서 추가 확인해야 합니다. Android/iOS 네이티브 카메라 SDK는 연결하지 않았으며 미지원 환경에서는 수동 입력을 유지합니다.
